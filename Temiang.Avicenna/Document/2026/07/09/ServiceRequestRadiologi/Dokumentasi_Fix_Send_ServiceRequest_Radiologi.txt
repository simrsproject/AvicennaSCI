/*
================================================================================
 LATAR BELAKANG MASALAH
================================================================================

 1. Tombol send service radiologi di menu realisasi kadang bisa kadang tidak.
 2. Petugas radiologi harus workaround ke menu "Send Outpatient" untuk kirim ulang.
 3. Muncul pesan "Success" tapi data tidak terkirim ke SatuSehat.

================================================================================
 PENYEBAB (ROOT CAUSE)
================================================================================

 A. Validasi parameter yang tidak diperlukan:
    - Sebelum kirim, sistem mengecek AppParameter ServiceUnitRadiologyID dan
      ServiceUnitRadiologyIdArray. Jika salah satu kosong -> langsung gagal.
    - Padahal parameter ini hanya dipakai sebagai filter internal di
      PostServiceRequestRad(), bukan prasyarat untuk proses pengiriman.

 B. PostServiceRequestRad() tidak dipanggil jika EncounterID sudah ada:
    - Fungsi OrderRadRealization() hanya memanggil PostServiceRequestRad()
      via EncounterAndRadOrderPost() (ketika EncounterID belum ada).
    - Jika EncounterID sudah ada (karena pernah diproses dari menu lain),
      fungsi langsung return "success" TANPA mengirim ServiceRequest radiologi.

 C. Return value OrderRadRealization() tidak dicek:
    - Fungsi SendServiceRequestToRis() dan SatusehatServiceRequestPostAndLogToRis()
      bertipe void dan tidak menangkap response dari OrderRadRealization().
    - Akibatnya pesan selalu "Success" meskipun gagal.

================================================================================
*/

/*
================================================================================
 DAFTAR VALIDASI ERROR YANG SEKARANG DITAMPILKAN
================================================================================

 | Kondisi                                    | Pesan Error                                          |
 |--------------------------------------------|------------------------------------------------------|
 | TransactionNo (JO) tidak ditemukan         | "Rad Order not found"                                |
 | RegistrationNo kosong di TransCharges      | "RegistrationNo is empty for order JOxxxxxx"         |
 | RegistrationNo tidak ada di tbl Registration| "Registration not found: REG/EM/xxxxxx"             |
 | OrganizationID belum diset                 | "SatuSehatOrganizationID empty"                      |
 | Patient belum mapping SatuSehat            | "Patient bridging not found"                         |
 | Dokter belum mapping SatuSehat             | "Requester bridging not found"                       |
 | Service Unit belum mapping SatuSehat       | "BridgingID for Service Unit xxx still empty"        |
 | Gagal buat Encounter (error lain)          | "Please contact IT Support"                          |

================================================================================
*/


/*
================================================================================
 CATATAN TAMBAHAN
================================================================================

 Untuk kasus JO260708-00567:
 - Error: "BridgingID for Service Unit ENDOSCOPY still empty"
 - Artinya: Service Unit ENDOSCOPY belum di-mapping Location ID SatuSehat
   di tabel ServiceUnitBridging.
 - Solusi: Insert mapping Location ID SatuSehat untuk unit ENDOSCOPY.

 Contoh query cek:
   SELECT * FROM ServiceUnitBridging
   WHERE ServiceUnitID = (SELECT ServiceUnitID FROM ServiceUnit WHERE ServiceUnitName LIKE '%ENDOSCOPY%')

 Contoh query insert (sesuaikan value):
   INSERT INTO ServiceUnitBridging (ServiceUnitID, BridgingID, SRBridgingType)
   VALUES ('<ServiceUnitID>', '<Location ID SatuSehat>', '<SatuSehatBridgingTypeID>')

================================================================================
*/
